Os 3 passos

  1. GitHub — crie o repositório vazio em github.com/new (nome: auxilio-farmacia, público, sem README). Extraia o ZIP e rode publicar-local.sh (ou publicar-local.bat no Windows).
  2. Cloudflare Pages (frontend) — Workers & Pages → Create → Connect to Git. Build command vazio, build output site. → auxilio-farmacia.pages.dev
  3. Hugging Face Spaces (backend) — new-space → Docker, suba a pasta api/, ative Persistent storage e configure as variáveis.

Depois: edite site/config.js apontando apiBase para a URL do Space, e cadastre o webhook do Asaas (URL do Space → /api/payments/webhook/asaas).

⚠️ Não use GitHub Pages para o site comercial. A documentação do GitHub proíbe o Pages para e-commerce e transações comerciais. Use Cloudflare Pages (grátis e permitido).
