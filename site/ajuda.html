❓ Perguntas Frequentes (FAQ)

O que é o Auxílio Farmácia? +
O Auxílio Farmácia é uma plataforma educacional para profissionais de farmácias, drogarias e atenção primária à saúde. Oferece informações sobre 61 medicamentos, 10 Classes terapêuticas, 9 calculadoras, 2 cursos completos e 7 módulos educacionais.
Quanto custa? +
Temos 4 planos: FREE (grátis, 30% dos recursos), PRO (R$ 29,90/mês, todos medicamentos + interações), PREMIUM (R$ 79,90/mês, tudo + cursos + certificado) e ENTERPRISE (R$ 297/mês, para instituições).
Como funciona o sistema de dispositivos (antipirataria)? +
Usamos device fingerprint (hash SHA-256 do seu navegador + tela + canvas). Cada plano tem limite: PRO = 2 devices, PREMIUM = 3, ENTERPRISE = 50. Se exceder, faça login no painel admin ou contate o suporte.
Posso usar offline? +
Sim! O dashboard é um arquivo HTML único que funciona 100% offline após primeiro carregamento. Apenas os vídeos do YouTube e fontes Google precisam de internet na primeira vez.
Os certificados são válidos? +
Os certificados digitais são válidos para horas complementares em faculdades de farmácia, mas não substituem certificados de cursos técnicos reconhecidos pelo MEC. Para certificação profissional formal, procure cursos técnicos profissionalizantes.
Posso usar o conteúdo para vender? +
Não. O conteúdo é protegido por direitos autorais. Pode usar para consulta pessoal/profissional, mas é proibida a reprodução, distribuição ou uso comercial sem autorização. Veja nossos Termos de Uso.
Como cancelar a assinatura? +
Você pode cancelar a qualquer momento no painel da sua conta, sem multa. O acesso continua até o fim do período pago. Após cancelar, sua conta volta automaticamente ao plano FREE.
Tem aplicativo mobile? +
Por enquanto, a plataforma é PWA (Progressive Web App). Você pode "instalar" no celular: abra no Chrome/Safari, clique em "Adicionar à tela inicial". App nativo (Android/iOS) está planejado para a versão 2026.11.

🐛 Problemas Comuns

O dashboard está lento

O dashboard tem ~1MB. No primeiro carregamento, pode demorar. Após isso, o navegador cacheia. Se persistir, tente limpar o cache ou usar outro navegador.

Login não funciona

Verifique se está usando o e-mail correto. Senha tem no mínimo 6 caracteres. Se esqueceu, use a opção "Esqueci minha senha".

Vídeos não carregam

Verifique sua conexão com a internet. Os vídeos são do YouTube e podem estar bloqueados em algumas redes corporativas. Tente em outra rede.

Curso não abre

Certifique-se de que está logado e tem plano PREMIUM ou superior. O botão "▶ Assistir" só aparece para esses planos.
